# Nifty 50 Price Prediction using Machine Learning

This project predicts the next day's Nifty 50 price using historical market data and Machine Learning.

## Features
- Data Cleaning & Preprocessing
- Feature Engineering
- Moving Averages (MA 7, MA 21)
- Train-Test Split
- Feature Scaling
- Model Training
- Model Evaluation

## Models Used
- Linear Regression
- Decision Tree Regressor

## Evaluation Metrics
- MAE
- MSE
- R² Score

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

## Prediction
The model uses today's market information to predict the next day's Nifty 50 price.
